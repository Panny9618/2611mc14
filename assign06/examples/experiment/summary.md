# Assignment 6 — Experiment summary

Mode: 5 separate OS processes over localhost TCP. Generated by `p2p experiment`.

## Checks

- ✅ **peer discovery: every node learned all 4 others from getaddr/addr** — 0.34 s; links [('n1', 'n2'), ('n1', 'n3'), ('n1', 'n4'), ('n1', 'n5'), ('n2', 'n3'), ('n3', 'n4'), ('n4', 'n5')]
- ✅ **tx injected at n2 reached all 5 mempools** — 0.17 s
- ✅ **each node downloaded the tx body at most once (duplicate suppression)** — tx bodies received {'n1': 1, 'n2': 0, 'n3': 1, 'n4': 1, 'n5': 1}; inv messages received {'n1': 2, 'n2': 0, 'n3': 2, 'n4': 2, 'n5': 1}
- ✅ **block mined at n5 reached all nodes; tx confirmed and removed from mempools** — 0.16 s, height 1
- ✅ **garbage before handshake: connection closed**
- ✅ **50 MB length prefix: closed before reading, peer banned, reconnect refused**
- ✅ **bad checksum / bad JSON / unknown command / bad schema / 1000-ping flood: rate-limited, scored, banned**
- ✅ **invalid block (broken PoW): peer banned**
- ✅ **n3 banned all three identities and kept its honest peers** — banned ['mallory1', 'mallory2', 'mallory3']; peers ['n1', 'n2', 'n4']; misbehaviour events 18
- ✅ **partition in place (no links across the sides)**
- ✅ **side A converged on its own block (height 2)**
- ✅ **side B mined two blocks (height 3) and disagrees with side A**
- ✅ **all 5 nodes converged on the most-work chain (side B's tip, height 3)** — 0.44 s; same tip and same UTXO-set hash on every node
- ✅ **tx from the stale block that is still valid returned to every mempool**
- ✅ **conflicting tx from the stale block was dropped everywhere**
- ✅ **final block from n2 accepted by all; mempools empty; all UTXO sets identical** — height 4, balances {'Alice': 52, 'Carol': 30, 'Bob': 29, 'miners': 204, 'Dave': 75}
